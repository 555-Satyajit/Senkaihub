# SenkaiHub

A premier anime clan community and social hub built with Next.js (App Router), React 19, TypeScript, and Tailwind CSS.

## Features
- **Dynamic Social Feed**: Anime community media, theory discussions, and double-tap Soul Shard ignition.
- **Clans & Guilds Directory**: Compete in seasonal Clan Wars, browse factions, and earn Victory Points (VP).
- **Automated CI/CD**: Verified with GitHub Actions linting, type checks, build validation, and CodeRabbit AI code reviews.

## Getting Started
```bash
cd frontend
pnpm install
pnpm dev
```
